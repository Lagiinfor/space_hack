Automatic mover search

The tool finds every point of light in each pass, links them across passes, and flags anything that shifted steadily by much more than ordinary stars wobble in this field. Each mover is then checked against Gaia: known means Gaia predicts that motion; candidate means nothing in Gaia explains it, so it is worth a human look. How to read it

  • Each frame is one sky pass. SPHEREx sweeps the whole sky about every six months.
  • Why bands? SPHEREx has no ordinary filters: the colour it sees changes across each of its 6 detectors, so each single photo sees a star at a different wavelength. We stack all photos from one detector in one pass, so every frame in a band covers the same wavelengths. Only real changes blink.
  • Movers jump between frames. Barnard's Star moves about 10″ a year, under 2 SPHEREx pixels.
  • Difference: each pass minus the average of all passes. Red = brighter than usual, blue = fainter. A mover shows as a red/blue pair that flips.
  • Gaia stars: circles show where ESA's Gaia catalogue says each star should be on that date. A star that moves with its circle is understood. Something that moves with no circle is worth a closer look.
  • Molecule lenses recolour the sky using wavelengths where molecules absorb. Ordinary stars come out white, so anything coloured has unusual chemistry.

Data: NASA/IPAC IRSA SPHEREx archive (DR1 + quick release), ESA Gaia DR3, CDS Sesame.
